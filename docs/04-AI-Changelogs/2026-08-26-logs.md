| Before | After | Why |
| --- | --- | --- |
| Desktop centered `Dialog` on mobile screen for cash/reversal confirmation | Bottom sliding `Drawer` (Vaul) with grab handle and gesture swipe | Mobile users expect bottom sheets within natural thumb reach |
| Static button click with no press feedback | `active:scale-[0.97]` and `transition: transform 160ms ease-out` | Buttons must feel physically responsive to press |
| Built-in linear/default CSS transitions | Custom curves (`cubic-bezier(0.23, 1, 0.32, 1)`) | Default curves lack intentionality; custom easings feel snappy and premium |
| Rigid table row hover with harsh borders | `transition-[background-color] duration-150 ease-out hover:bg-accent/40` + `border-border/40` | Subtle contrast changes feel smoother and less distracting |
| Default basic Sonner toasts | Glassmorphic floating toast (`bg-card/95 backdrop-blur-md shadow-xl rounded-2xl`) | Cohesive toast styling elevates overall perceived quality |
| Fixed 9px standard tab height on mobile | `h-12 p-1 rounded-2xl bg-muted/60` with smooth active pill elevation | Touch targets must be $\ge 44\text{px}$ with clear spatial active state |
